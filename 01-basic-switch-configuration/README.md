# Basic Switch Configuration

## Objective

Configure a Cisco switch and verify basic connectivity between devices.

## Topology

- 1 Cisco Switch
- 2 PCs
- Ethernet cables

## Configuration

The switch was configured using Cisco IOS commands.

## Verification

Connectivity was tested using the `ping` command.

## Tools Used

- Cisco Packet Tracer
- Cisco IOS

## Skills Practiced

- Basic switch configuration
- CLI navigation
- Interface configuration
- IP addressing
- Connectivity testing
